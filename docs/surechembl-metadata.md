# SureChEMBL document metadata

Check [source permissions](source-licenses.md) and current operation descriptions with `capabilities(source="surechembl")`. The source53 changes are awaiting consolidated qualification.

Ordinary `search(entity="patent", query=...)` uses SureChEMBL's current metadata search. Results retain document identity, reported publication date and literal assignee, plus a source citation URL. Missing dates and assignees remain null. Underlying patent text, claims, drawings and attachments are outside the released scope.

Use `query_source` with `get_patent_statistics`, an explicit source query, `group_by`, `limit` and `page`. Counts describe acquired document records. They do not count unique patent families or normalized corporate entities. Read `denominator`, `coverage`, `population_statistics_status` and `input_locators`; a provider population total does not make a displayed window complete. Execute the supplied `next_actions` to continue. Missing grouping measurements remain unknown. Classification fields are not supplied by this response contract.

`search_similar_structures` starts a source similarity job once, validates its SMILES/method/filter identity, and reports either pending status or a scored compound window. Pending status has an unknown total and remains partial. Execute the returned signed action after `retry_after_seconds` to check the same job; subsequent actions retrieve its next page. Continuations bind account, SMILES, threshold, window size and implementation revision and use the shared runtime store, including local CLI persistence. Expired or unavailable cursor storage does not silently create another job.

Scores are source-reported Tanimoto similarities over hashed binary chemical fingerprints. The precise fingerprint algorithm/version and structural normalization remain unqualified. A high score does not establish shared target binding or biological function. Every emitted score is checked against the requested threshold. Source job metadata does not echo that threshold: the signed request and server-stored job context preserve its binding. Source counts and completed status describe the source search, not exhaustive acquisition of its results.

`analyze_patent_chemistry` accepts an explicit publication identifier. Compact identifiers are normalized by the source; multiple matches remain ambiguous. The result retains derived annotations from abstracts, descriptions and claim sections: source category, chemical identifiers and positions. Coordinates use JavaScript UTF-16 code units over source HTML (zero-based start, exclusive end); the source text and matched snippets are excluded from both cached evidence and recoverable resources.

`categories` counts source annotation records by their reported category. `frequency` counts chemical-identifier memberships in those records; a record with multiple mappings can contribute to more than one identifier. Missing and multiple mappings remain partial. These are not patent-family frequency, exposure, novelty or legal-scope measurements. Source annotation `globalFrequency` is retained separately from compound-card `global_frequency`; their definitions and release alignment are not qualified. Missing annotations remain unknown; explicit empty annotations apply only to the selected source sections. Drawings, attachments, amended claims and other unparsed collections are outside coverage.

The three public advanced operations now have current-contract implementations and passing native/Docker regression fixtures. Retained exact/family/chemical primitive aliases outside the public advanced interface remain blocked pending their separate current contracts. API keys cannot unlock underlying patent text or bypass source permissions.
